# Projeto de Compressão de Imagens

## 1. Sobre o Projeto
Este projeto consiste no desenvolvimento de uma aplicação prática (Software) voltada à compressão de imagens[cite: 1]. O problema central que motiva esta ferramenta é a necessidade de reduzir o tamanho de arquivos de imagem, facilitando o armazenamento e o compartilhamento dos mesmos[cite: 1].

**Tema:** Compressão de Imagens[cite: 1]
**Categoria:** Opção 4 - Aplicação Prática (Software)[cite: 1]

## 3. Escopo e Funcionamento
O funcionamento da aplicação é baseado em duas informações fundamentais fornecidas pelo usuário:
* A imagem original de entrada[cite: 1].
* O tamanho máximo desejado para o arquivo final (inferior ao tamanho original)[cite: 1].

A partir dessas entradas, a ferramenta realizará um processo de compressão automático[cite: 1]. O resultado será uma nova versão da imagem, otimizada para atingir o tamanho limite definido, enquanto mantém a maior qualidade visual possível[cite: 1]. 

O projeto também abrange análises e testes práticos para avaliar a relação direta entre o tamanho final atingido e a qualidade visual da imagem resultante[cite: 1].
